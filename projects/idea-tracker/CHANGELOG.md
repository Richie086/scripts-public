# Changelog

All notable changes to Idea Forge (and its companion plugins) are documented
here. Format loosely follows [Keep a Changelog](https://keepachangelog.com/),
versioning follows [SemVer](https://semver.org/). This file is updated
whenever a new feature is requested and implemented.

## [Unreleased]

## [0.4.0] - 2026-07-14

### Changed

- Refactored Admin Settings UI into a modern, responsive Tabbed Configuration Hub separating General, Security Keys, and Integration settings.
- Restructured provider configuration cards to match Dracula color variables with beveled border highlights and resting depth shadows.
- Added password show/hide visibility toggles to AI provider API Key input fields.
- Added live JSON validation indicator for custom HTTP headers.
- Replaced full-page reloads for Connection Testing with an interactive AJAX/Fetch loader and inline status badge widget.

## [0.3.6] - 2026-07-11

### Fixed

- Assist now clears stale per-entry drafts when an action fails and shows
  explicit action-scoped error messages (for example, provider/key/network
  failures) so button clicks no longer appear to "do nothing."

## [0.3.5] - 2026-07-11

### Changed

- Assist-generated output previews are now hard-capped at 20,000 characters
  across all actions to keep preview payloads bounded and consistent.

## [0.3.4] - 2026-07-11

### Changed

- Assist apply now tracks each action section with hidden markers and, on
  append, replaces the existing section for the same action instead of
  duplicating blocks when you generate a newer draft for that action.

## [0.3.3] - 2026-07-11

### Changed

- Every Assist-applied section now starts with a clear H1 warning block stating
  the content was created using Assist and generated by AI (which can make
  mistakes), plus action/provider metadata.

## [0.3.2] - 2026-07-11

### Changed

- Assist draft apply now normalizes Markdown before saving: heading marker
  spacing is fixed, ordered lists are renumbered sequentially, and unclosed
  fenced code blocks are automatically closed so appended sections stay clean.

## [0.3.1] - 2026-07-11

### Changed

- Tightened **Suggest Features** generation rules so the action now enforces a
  top-level numbered list with a minimum of 5 and maximum of 10 feature
  suggestions, including one corrective regeneration pass and a clear error if
  the provider still returns an out-of-range result.

## [0.3.0] - 2026-07-11

### Added

- New per-item AI Assist actions in Idea Forge:
  - **Master Prompt**: generates a structured, reusable master prompt for external AI tools using current-item context only.
  - **Create Scaffold**: generates implementation scaffolding suggestions including platform, OS, languages, database, frontend/backend, and system type.
  - **Deployment Script**: generates deployment planning + script templates across Proxmox VM, VMware VM, containers, Azure VM, AWS EC2/container, VirtualBox, and Virt Manager.
- Expanded **Suggest Features** action output to include prioritization and implementation-focused details (impact, approach, complexity, dependencies/risks).
- Updated item detail Assist copy and README documentation to describe the new AI actions and run-time provider selection behavior.

### Changed

- AI action prompt context now explicitly includes current-item status and tracker IDs (Jira/Bitbucket/GitHub) to improve output relevance while keeping scope to the active item.
- Smoke test now exercises the new AI actions in mock mode (`master_prompt`, `features`, `scaffold`, `deployment`) in addition to existing actions.

## [0.2.0] - 2026-07-11

### Added

- Antigravity export plugin (`projects/idea-forge-antigravity-export/`): a
  VS Code-family extension for Google's Antigravity IDE that discovers the
  user's global (`~/.gemini/GEMINI.md`, `~/.gemini/AGENTS.md`) and project
  (`GEMINI.md`, `AGENTS.md`, `.agent/rules/*.md`) instruction files and
  exports selected ones into Idea Forge as new entries via the existing
  `/api/ingest/agents-md` API, plus a new batch variant of that endpoint
  for exporting several files in one action.
- `CHANGELOG.md` and `VERSION` for tracking future feature work.

## [0.1.0] - 2026-07-10

### Added

Baseline snapshot of everything built before changelog tracking started:

- Entries: categories, quick capture, pins, related-entry linking, category
  templates, external tracker IDs (Jira/Bitbucket/GitHub).
- Local git forge: bare repos, Smart HTTP (token auth), embedded SSH, web
  file browser (tree/blob/commits/diffs), pull requests, garden repo that
  auto-versions every entry change as Markdown.
- Full-text search (SQLite FTS5) across titles, notes, tags, URLs, and
  attachment names; collections/stacks; JSON export/import.
- Media attachments: images, audio, PDF, Word, HTML/CSS/Markdown/config,
  with "insert into notes" support.
- AI Assist: OpenAI, xAI/Grok, Google/Gemini, Anthropic/Claude, GitHub
  Models, with encrypted per-provider key storage.
- AGENTS.md ingest: timestamped entries, `ingest_events` log, dedicated
  `agents-md-history` collection, garden-versioned, CLI + HTTP API
  (`POST /api/ingest/agents-md`).
- UI redo: JetBrains Mono font, GitHub markdown light/dark themes, theme
  toggle, admin path browser (allowlisted roots).
- Deploy: free-tier AWS Docker deploy (EC2 `t3.micro` + Docker Compose +
  Caddy HTTPS + SSM, no inbound SSH), live at
  `https://ideaforge.extremesarcasm.org`; security group locked to a
  customer-managed IP prefix list.
- `bash/scan_pii.sh`: pre-upload/pre-publish scanner for emails, keys, and
  secret-like content, wired into the AWS deploy script before any S3
  upload.
